## Scope

The pitch covers:

- private-only scoring
- capability/parameter hierarchy
- guided index builder, presets, voice
- rank stability
- benchmark checks
- task clock, provider spread, monthly tiers, availability
- coding-tool plans and stacks
- model-vs-model compare
- alternate boards, score breakdown, nearest neighbours
- ternary, volume field, time Pareto; human gap, stability, provider lottery

It does not propose anything Priors already has.
