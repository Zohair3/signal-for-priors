## How to use these

- In a feature spec, use the screenshot as the visual reference, but keep the behavior and edge cases from the markdown.
- Do not copy Signal’s colors, copy, or layout into Priors. Use the screenshots to explain the interaction, not to clone the design.
- Do not use a landing-page screenshot as evidence for a feature. If a feature is below the fold, capture the feature itself.

## Re-capturing

The products change daily. If a screenshot is stale, re-capture the live feature and update this table. Do not edit the image to change a number.
